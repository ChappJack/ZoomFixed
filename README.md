## INSTALLATION NOTES
There is a build.ps1 file for auto building everything. I couldn't get it to work.  
What I did was just cd into the ZoomFixed folder location, installed the Geode CLI and SDK, downloaded environment variables, and ran geode build.

## UNWILLING TO BUILD?
Don't worry! If you don't want to build from your computer, you can use my build at prebuild/bobby_shmurner.zoom.geode.
